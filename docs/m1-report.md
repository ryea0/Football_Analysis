## 真实数据边角问题与修复（TDD）

首次全量拉取暴露 9 份文件入库失败（其余 161 份不受影响，单文件容错按预期工作）：

```
E0 2003-04 / E0 2004-05 / SP1 2004-05 / D1 2002-03 / D1 2003-04
I1 2003-04 / I1 2004-05 / F1 2002-03 / F1 2003-04
  ParserError: Error tokenizing data. C error: Expected N fields in line M, saw K
```

定位：这些赛季的部分数据行行尾多出若干逗号，字段数比表头还长且多出的**全为
空**。扫描全部 170 个缓存文件：868 行属「尾部多余空字段」类，**0 例**多出非空
字段（另有 12,881 行字段数少于表头，pandas 本就容忍、填 NaN，无需处理）。

修复（commit `a4a9726`）：`parse_csv` 读入前先 `_trim_ragged_lines` 截掉行尾
多余空字段——仅在「多出部分全为空」时截断；带非空值的多余字段维持 pandas 报错
上抛（由 sync 记账），不静默吞数据。先补 3 个失败测试再修：

1. 尾部多余空字段的行可解析且各列取值正确
2. 列数与表头一致的文件逐字节原样返回（裁剪不误伤）
3. 非空多余字段仍抛 `ParserError`（保持严格性）
