# M3 B 线运营栈 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** B 线第一个里程碑——实时盘接入、价值层推荐、paper 自动落注结算、TG 报告与双线 status，使 §12 协议的 B 线开始累积前向证据（结论与 A 线分账）。

**Architecture:** `fa/pipeline/` 新包承 B 线（odds→fixtures→fit→value→paper→report），OddsProvider 抽象隔离 The Odds API；schema v3 加 5 张表（fixtures/odds_snapshots/recommendations/bets/runs，加法迁移）；模型与门槛常量复用现有 `fa/model` 与 `fa/value`（单一事实源）；报告经 `hermes send` 出 TG。**表边界（§12.1）**：本线绝不写 `backtest_predictions`。

**Tech Stack:** 既有栈零新增（stdlib urllib/json/subprocess + pandas/scipy/typer/pytest）。

**Spec:** `spec.md` v0.5——§12（双线协议）、§3.1/3.3/3.4（实时源/对齐/额度）、§5（价值层）、§7（报告与 paper 台账）、§9.3/9.6（CLI/调度语义）、§9.8（Provider 抽象）。执行者必读 §12。

## Global Constraints

- **表边界硬约束（§12.1）**：B 线只写 `fixtures/odds_snapshots/recommendations/bets/runs/meta`，绝不写 `backtest_predictions`/`matches`（matches 仅由 A 线数据层 `sync-history` 写）
- **真实下注禁止（§12.2）**：`bets.mode` 只允许 `paper`；`fa bet add` 人工登记是唯一 live 入口（默认 paper，live 需显式 `--live` 并二次确认）
- 门槛与仓位常量**单一事实源**：`fa/value/gates.py`（EV_MIN=0.03、EDGE_MIN=0.02、ODDS_MIN=1.4、ODDS_MAX=6.0、KELLY_FRAC=0.25、STAKE_CAP=0.02，spec §5.2/5.3 逐字）——`fa/backtest/simulate.py` 改为从此 import 并 re-export（既有测试不改即过）
- 额度纪律（§3.4）：每次 Odds API 响应的 `x-requests-remaining` 写 `meta`（key=`odds_quota_remaining`）；低于 100 时 pm 相位跳过拉盘改用 am 快照并在报告标注
- 大小球只取 `point == 2.5`（spec §11 风险 #4）；市场概率 = **可成交最优价**（各 bookmaker 同 outcome 最大赔率）三选一比例去水
- 网络仅允许出现在 `fa/pipeline/odds_api.py` 与 `fa/report/telegram.py`（hermes send）；单元测试一律离线（fixture JSON / monkeypatch）
- hermes 交互：`hermes send --to telegram`（subprocess，timeout 60s，失败→降级记 runs 不中断管线）；persona（M4）不在本计划
- 队名未知绝不静默丢弃（§3.3）：进 `unknown_names` + 报告可见
- 依赖零新增；提交 conventional；CLI 输出中文；测试 `uv run pytest ...`
- 计划级设计裁定（对 spec §3.2 的具体化，已由控制器裁定）：未赛对阵存新表 `fixtures`（`recommendations.fixture_id` 外键）；`odds_snapshots.match_id` 字段取消，改 `fixture_id`（可空）——spec 原文 `match_id 可空` 的意图即「对齐完成前可空」，指向 fixtures 语义更诚实
