# M2 go/no-go 判决书

- 日期：2026-09-03
- 窗口：2019–2025 赛季（7 个赛季，spec §8.1 要求 ≥5），**11,605 场**（仅含 Pinnacle 收盘 `psc_*` 覆盖场次；窗口内全部 12,459 场中 854 场无收盘价，见「数据说明」）
- 主判决（half-life=100，σ=0.35 默认）：**⛔ NO-GO**
- 稳健性：half-life 50/200/400 与 σ 0.5/0.8/1.5/3.0 双轴扫描**全部 NO-GO**（见「调参对比」「补充：σ 先验扫描」）
- 模型 log-loss **0.99790** vs 市场（去水收盘）**0.96867**（劣化 **+3.02%**，判据 ≤ +1.00% → **超标 3.0 倍**）
- Brier：模型 **0.29776** / 市场 **0.28783**
- 校准：**过度收缩（shrinkage 过强）**——主胜概率在高概率端**低估**（0.7–0.8 十分位：预测 0.740 / 实际 0.782，−0.042），在低概率端**高估**（0.0–0.1：预测 0.083 / 实际 0.054，+0.029）；中段（0.3–0.6）基本贴合。这是模型离散度不足的直接证据：模型 p_home 标准差 **0.148** vs 市场 **0.186**（P5–P95：0.200–0.688 vs 0.147–0.764）。

## 证据链（模型确实有信号，但不够）

| 基准 | log-loss | 相对模型 |
|---|---|---|
| 常数频率基线（全样本 H/D/A 频率） | 1.07449 | 差 +7.7% |
| **本模型（hierarchical DC, hl=100）** | **0.99790** | — |
| Pinnacle 收盘去水 | 0.96867 | 好 −2.9% |

模型显著优于无信息基线（管线拟合、去水、评估链路无缺陷），但**没有跑赢收盘价**。市场自身校准极紧——**所有 n ≥ 100 的十分位** |预测−实际| ≤ 0.027（唯一例外是 0.9–1.0 尾桶：n=13，差 +0.087，属纯二项噪声、无统计意义），证实评估链路与比例法去水无误——差距是真实的模型能力差距，不是 harness 假象。

## 模拟盘（收盘价成交，保守）

- 平注：**9,679 注**，ROI **−5.6%**（精确 −5.55%，P&L −537.7 单位）
- ¼ Kelly（本金 1000，单注 ≤2%）：终值 **0.0**（精确 0.0023），ROI **−100.0%**，最大回撤 100.0% —— 爆仓

**参照系（本项目自行补测）**：若不做任何筛选、对 11,605 场的 34,815 个结果全部平注收盘价，ROI = **−3.73%**（即纯水位成本）。模型的 −5.55% **比无脑全押更差**——筛选反而带来负选择。

原因诊断（非缺陷，是 NO-GO 的机理）：门槛几乎不构成筛选。两个必须分开看的口径——

| 口径 | 场次数 | 占 11,605 |
|---|---|---|
| **edge 通过率**：≥1 个结果满足 `edge ≥ 0.02`（仅此一条） | 10,261 | **88.4%** |
| 同上，再加 `EV ≥ 0.03`（未加赔率窗） | 10,011 | 86.3% |
| **实际下注覆盖率**：再加赔率窗 `1.4 ≤ odds ≤ 6.0`（= `candidates()` 全部门槛） | 8,692 | **74.9%** |

即 **74.9% 的场次产生下注**（8,692 场 / 9,679 注，平均 edge 0.066）。88.4% 是 edge 单条通过率，74.9% 才是真实下注覆盖率——两者都不该叫「筛选」。模型相对市场过度收缩，其概率与市场之差的均值为零但方差大（corr(p_home) 仅 0.89），于是「edge」大多是**模型噪声**而非信息增量——按它下注等于在收盘价上做负 EV 的长注偏选（模型平均高估客队 +0.0082、低估主队 −0.0083）。

## 调参对比（supplementary，主判决仍为 half-life=100）

| half-life（天） | 模型 log-loss | 劣化% | 平注 ROI（注数） | 判决 |
|---|---|---|---|---|
| 50 | 1.01096 | +4.37% | −5.9%（10,338） | NO-GO |
| **100（默认，主判决）** | **0.99790** | **+3.02%** | **−5.55%（9,679）** | **NO-GO** |
| 200 | 0.99100 | +2.31% | −6.8%（9,203） | NO-GO |
| 400 | 0.98973 | +2.17% | −6.5%（8,957） | NO-GO |

劣化随半衰期拉长单调改善但**快速趋于平台（≈ +2.1%）**：50→100 提升 1.35pp，100→200 提升 0.71pp，200→400 仅 0.14pp。**没有任何合理的 half-life 取值能降到 +1% 门槛以内**（需从 +2.17% 再降一半以上，外推已饱和）。因此 NO-GO 不是超参选择问题，加大历史窗口也无法挽救。半衰期拉长虽改善 log-loss，平注 ROI 反而更差（−5.6% → −6.8%）——log-loss 与盈利在本区间内不同向。

> 诚实声明：以上扫描为稳健性检验，目的在于证明**判据无法通过**；主判决严格采用 spec 默认参数 half_life_days=100 的那一次运行，未做任何朝 GO 方向的调参。

## 补充：σ 先验扫描（终审后补全）

主判决落档后补做的第二根超参轴：队级先验宽度 `sigma_att = sigma_dfn`（`--sigma`，CLI 于终审后补透传；`sigma_mu`/`sigma_ha` 保持默认 0.25——联赛级收缩不是诊断出的瓶颈）。窗口、数据与评估口径与主判决完全一致（2019–2025，11,605 场，市场 log-loss 恒为 0.96867）。σ 越大 = 先验越宽 = 队级收缩越弱。

| σ（sigma_att=sigma_dfn） | 模型 log-loss | 劣化% | 平注 ROI（注数） | 判决 |
|---|---|---|---|---|
| **0.35（默认，主判决，已归档）** | **0.99790** | **+3.02%** | **−5.55%（9,679）** | **NO-GO** |
| 0.5 | 0.99606 | +2.83% | −5.32%（9,600） | NO-GO |
| 0.8 | 0.99768 | +3.00% | −5.67%（9,708） | NO-GO |
| 1.5 | 1.00079 | +3.32% | −5.27%（9,779） | NO-GO |
| 3.0 | 1.00322 | +3.57% | −5.56%（9,838） | NO-GO |

**解读：σ 轴是平的，且机理上揭示了「过度收缩」只是症状而非病因。** 全轴都在 +2.8%～+3.6% 之间：最优点 σ=0.5 也只把劣化从 +3.02% 降到 +2.83%（−0.19pp），离 ≤1% 门槛还差 1.8pp；曲线在默认值附近呈浅谷、之后随 σ 单调变差（0.8 → 3.0 一路上升），与 half-life 轴的 +2.17% 平台互相印证——**两根超参轴都到不了关卡**。更关键的是反向证据：σ=3.0 时模型 p_home 标准差升至 **0.199**（默认 0.148，市场 0.186），即判决书指出的「概率离散度不足」**是可以被弥合的**，弥合后 log-loss 反而更差（+3.57%）。说明额外的锐度来自队级参数在 ~1,000 场加权样本上的噪声放大（过拟合），并非信息增量；把预测「拉宽到市场形状」不等于「比市场更准」。平注 ROI 在所有 σ 下均停在 −5.3%～−5.7%，无一转正。M2 的 NO-GO 结论与机理诊断在 σ 轴上同样成立。

> 诚实声明：默认 σ=0.35 的那一次运行即**预注册的主判决**；在同一评估窗口（2019–2025）上扫描 σ 得到的任何更优取值，都属于**样本内超参选择（in-sample hyperparameter selection）**，其本身**不重开关卡**。若某个 σ 在本窗口越过 ≤1% 门槛，仍需**样本外确认**（如留出的 2025-26 部分赛季，或一次全新的预注册运行）才具备重评资格，且是否重启由项目负责人决定。本次扫描未出现任何越线取值（最低 +2.83%），故仅作稳健性留档，不改变判决。

## 结论

**NO-GO。** 模型 log-loss 相对 Pinnacle 收盘去水劣化 +3.02%，超 spec §8.2 的 +1% 判据 3.0 倍；五联赛、七赛季、四个 half-life 取值与四个 σ 取值（0.5/0.8/1.5/3.0，见补充节）下**无一达到 GO**。机理明确：分层 DC + MAP 收缩产生的概率离散度系统性低于市场（过度收缩），在收盘价上无信息增量，模拟盘确认负 EV（平注 −5.6%，¼ Kelly 爆仓）。

**按 spec §10 M2 与 §1「跑不赢市场就止步」：项目止步于研究结论，M3+（persona、实时盘、下单）不启动。**

可留档的研究发现（若未来重启）：模型确有信号（优于常数基线 7.7%），主要缺口是概率锐度而非方向——~~放宽 σ_att/σ_dfn 先验~~（**已被 σ 扫描排除**：σ=3.0 时 p_home 离散度追平市场 0.199 vs 0.186，log-loss 反而劣化到 +3.57%，见补充节）、缩短窗口（half-life 200–400 已示 +2.2% 平台）两根超参轴均到不了关卡；剩余方向是对 1X3 以外市场（大小球/BTTS，本次因缺收盘赔率未入模拟盘）单独评估，以及更换建模思路本身（而非调参）。
